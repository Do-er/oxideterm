# OxideTerm Windows 编译与打包环境配置引导

本文档为 Windows 平台开发者提供从零配置 **OxideTerm 编译、开发调试与正式打包** 的完整环境指引。

---

## 1. 目标环境规范

- **操作系统**：Windows 10 / Windows 11 / Windows Server (x86_64)
- **编译目标**：`x86_64-pc-windows-msvc`
- **支持功能**：GPUI 渲染、Wasmtime 插件扩展、SSH/SFTP 密码学底层、Python 原生打包脚本及 NSIS 安装程序制作。

---

## 2. 核心工具链安装清单

| 工具 / 组件 | 最低建议版本 | 必需性 | 作用与说明 |
| :--- | :--- | :---: | :--- |
| **Rust 工具链** | `1.97.0` | **必需** | 主语言编译器与包管理器（需带 `rustfmt`、`clippy` 组件） |
| **VS Build Tools / MSVC** | VS 2022 (v143) | **必需** | 提供 MSVC C++ 编译器（`cl.exe`）、链接器（`link.exe`）及 Windows 10/11 SDK |
| **NASM 汇编器** | `2.16.x` | **必需** | SSH 与加密组件（`russh` -> `aws-lc-sys`）底层汇编加速编译 |
| **CMake 工具** | `3.25+` | **必需** | Wasmtime 插件运行时与 C 原生依赖编译 |
| **Git** | `2.40+` | **必需** | 源码版本管理与 Cargo Git 依赖拉取 |
| **Python** | `3.11+` | **打包必需** | 运行官方打包发布脚本 `scripts/release/package_native.py` |
| **NSIS** | `3.08+` (建议 3.10+) | **安装包可选** | **用于制作 Windows 正式安装程序 (`-setup.exe`)**。若只打包绿色便携版 (`.zip`) 则无需安装 |

---

## 3. 分步安装与配置指南

### 3.1 安装 Visual Studio Build Tools (C++ & Windows SDK)
1. 前往微软官网下载 [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)。
2. 安装时勾选 **“使用 C++ 的桌面开发”** 工作负荷，并确保右侧勾选了：
   - MSVC v143 - VS 2022 C++ x64/x86 生成工具
   - Windows 10/11 SDK（如 `10.0.26100.0` 或更高版本）
   - 用于 Windows 的 C++ CMake 工具

### 3.2 安装并配置 Rust 工具链
1. 安装官方 `rustup`（[https://rustup.rs](https://rustup.rs)）。
2. （可选）为国内网络配置持久化环境变量以加速下载：
   - `RUSTUP_DIST_SERVER = https://mirrors.ustc.edu.cn/rust-static`
   - `RUSTUP_UPDATE_ROOT = https://mirrors.ustc.edu.cn/rust-static/rustup`
3. 部署项目指定的工具链版本与扩展组件：
   ```powershell
   rustup toolchain install 1.97.0-x86_64-pc-windows-msvc
   rustup default 1.97.0-x86_64-pc-windows-msvc
   rustup component add rustfmt clippy
   ```

### 3.3 安装 NASM 汇编器（解决 aws-lc-sys 编译失败）
1. 从官网下载官方 Windows x64 安装包或绿色包：[NASM 官方下载页面](https://www.nasm.us/)。
2. 安装或解压（推荐路径：`C:\Users\<用户名>\AppData\Local\Programs\NASM`）。
3. 将包含 `nasm.exe` 的目录添加至 Windows 用户或系统环境变量 **`Path`** 中。
4. 在新终端运行 `nasm -v` 验证是否输出版本信息。

### 3.4 确保 CMake 位于 PATH 中
- 如果安装了 Visual Studio，内置 CMake 位于：
  `C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\Common7\IDE\CommonExtensions\Microsoft\CMake\CMake\bin`
- 将此路径添加到环境变量 **`Path`** 中，并在终端输入 `cmake --version` 验证。

### 3.5 安装 NSIS（制作 Windows 安装包专属）
NSIS（Nullsoft Scriptable Install System）用于执行 `package_native.py` 时生成最终的 `OxideTerm_<版本>-setup.exe` 安装向导。

#### 安装方式一：使用 winget（官方包管理器，需网络畅通）
在终端中执行：
```powershell
winget install NSIS.NSIS
```

#### 安装方式二：官网直接下载（推荐，稳定可靠）
由于 SourceForge 在部分网络环境下直接拉取可能超时，可直接访问官网下载：
1. 访问 [NSIS 官方下载页](https://nsis.sourceforge.io/Download)。
2. 下载最新的 `nsis-3.xx-setup.exe` 并完成安装（默认路径为 `C:\Program Files (x86)\NSIS`）。
3. 将包含 `makensis.exe` 的路径（如 `C:\Program Files (x86)\NSIS`）添加至 Windows 环境变量 **`Path`** 中。
4. 验证命令：
   ```powershell
   makensis -VERSION
   # 预期输出类似：v3.13
   ```

> [!TIP]
> **未安装 NSIS 时的便携构建**：
> 项目已内置容错机制。如果系统未安装 NSIS，执行 `python scripts/release/package_native.py` 会自动跳过 setup 安装向导制作，继续完整打包生成全套开箱即用的绿色便携压缩包（`.zip`）。

## 4. 国内网络与编译优化配置

为避免依赖拉取超时或 Git 证书错误，建议配置 `C:\Users\<用户名>\.cargo\config.toml`：

```toml
[net]
# 使用本机原生 Git 客户端拉取仓库依赖，规避 Windows SChannel SSL 校验异常
git-fetch-with-cli = true

[http]
# 避免部分企业内网或代理下的证书吊销链校验失败
check-revoke = false

[registries.crates-io]
# 使用 USTC sparse 镜像源极速同步 crates 索引
protocol = "sparse"

[source.crates-io]
replace-with = 'ustc'

[source.ustc]
registry = "sparse+https://mirrors.ustc.edu.cn/crates.io-index/"
```

## 5. 一键环境自检清单

在终端中执行以下命令，确认所有工具链均已就绪（均应输出版本号）：

```powershell
rustc -V
cargo -V
nasm -v
cmake --version
git --version
python --version
makensis -VERSION   # 仅打包 -setup.exe 安装向导时必需
```

## 6. 验证编译与打包命令

环境配置完成后，可通过以下命令验证开发与打包能力：

1. **快速语法与类型校验（最快，不耗费磁盘）**：
   ```powershell
   cargo check -p oxideterm-gpui-app
   ```
2. **本地启动体验（Debug 增量模式）**：
   ```powershell
   cargo run -p oxideterm-gpui-app -j 4
   ```
3. **官方原生正式打包（产物位于 `dist/` 目录）**：
   ```bash
   python scripts/release/package_native.py
   ```
   - 若已安装 NSIS：同时产出 `-setup.exe` 安装包与 `_portable.zip` 便携包。
   - 若未安装 NSIS：自动跳过安装向导，产出包含完整图标和运行库的 `_portable.zip` 便携包。
