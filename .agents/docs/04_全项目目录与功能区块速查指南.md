## 1. 根目录概览

在软件根目录下，主要包含以下几个核心文件夹：

| 目录/文件 | 它是干什么的（用大白话说） | 你需要改动它吗？ |
| :--- | :--- | :--- |
| **`crates/`** | **软件的“全身骨肉”**。包含整个客户端的所有代码，拆分成了 70 多个积木包（Crates）。界面、终端、网络连接都在里面。 | **主要改动区**（由 AI 修改） |
| **`assets/`** | **静态资源仓库**。存放软件内置的图标（SVG/PNG）、字体、默认配置文件等。 | **偶尔需要**（换图标、加字体时） |
| **`mydoc/`** | **知识库与文档手册**。存放为你整理的调试教程、架构说明、界面地图等。 | **随时阅读与查看** |
| **`scripts/`** | **辅助自动化脚本**。打包安装包、发布新版本、检查依赖的脚本工具。 | 极少需要 |
| **`.agents/`** | **AI 协作规则库**。存放 AI 助手在本仓库的开发规则、编译安全限制与专项技能。 | 不需要改动 |
| **`Cargo.toml`** | **工程总清单**。记录所有子模块和第三方依赖库的版本信息。 | AI 自动维护 |

## 2. 界面积木总指挥部：`crates/oxideterm-gpui-app`

这是你调整**功能布局、显示风格、交互体验**最核心的目录。软件窗口从启动到把按钮、标签、侧边栏渲染出来的过程全在这里。

所有界面组件都集中在 `src/workspace/` 目录下，对应屏幕上的具体功能：

```
                    【OxideTerm 界面结构映射】
┌─────────────────────────────────────────────────────────────┐
│ 顶部标签栏 (tabs/) & 窗口控制按钮                           │
├───────────────┬─────────────────────────────────────────────┤
│               │ 终端中央画布 (terminal_entity.rs)           │
│ 侧边栏/抽屉   │ - 多终端分屏 (pane_tree.rs)                 │
│ (sidebar/)    │ - 黑底白字交互                              │
│ - 会话树      ├─────────────────────────────────────────────┤
│ - SSH节点     │ 快捷命令发送条 (terminal_command_sender.rs) │
│ - SFTP入口    │ - 批量广播/单终端发送/历史指令              │
└───────────────┴─────────────────────────────────────────────┘
  ★ 悬浮层/弹窗：
    - 全局命令面板 (command_palette/)：按快捷键弹出的搜索框
    - 设置中心 (settings/)：全局偏好设置窗口
    - 快速命令库 (quick_commands_view.rs)：保存的常用运维脚本
    - AI 助手面板 (ai_state.rs)：智能运维对话框
```

### 界面核心模块详细对照表：

| 模块目录 / 文件名 | 对应屏幕上的位置与功能 | 典型需求举例 |
| :--- | :--- | :--- |
| **`workspace/tabs/`** | **顶部标签页栏**：管理多个打开的终端或会话标签，支持新建、切换、关闭、右键菜单。 | “我想把标签页高度调小一些”、“想要双击标签页重命名” |
| **`workspace/sidebar/`** | **左侧/右侧边栏**：显示已保存的主机列表、标签分组、快速入口图标。 | “我想把侧边栏挪到右边”、“想加一个隐藏/收起侧边栏的按钮” |
| **`workspace/pane_tree.rs`** | **分屏网格系统**：控制屏幕左右拆分、上下拆分，拖拽分屏边缘调整大小。 | “希望默认分屏比例是 50:50”、“希望分屏边框线条更细一点” |
| **`workspace/terminal_command_sender.rs`**<br>`terminal_command_bar/` | **底部快捷命令条**：底部一个输入框，可以在不聚焦终端时输入命令并按回车发送，支持批量发送到多个终端。 | “我想把命令输入条默认隐藏”、“想把它移到顶部”、“想要支持多行输入” |
| **`workspace/command_palette/`** | **Ctrl+P 命令搜索面板**：类似 VSCode 的快速搜索弹窗，用于搜索命令、快速连接服务器。 | “搜索弹窗太宽了”、“我想在弹窗里直接搜历史记录” |
| **`workspace/quick_commands_view.rs`** | **常用命令列表/快捷指令抽屉**：存放常用的 Linux 脚本片段，点击直接在终端运行。 | “我想把常用命令做成常驻按钮组”、“想给命令加分组文件夹” |
| **`workspace/sftp/`** | **SFTP 文件管理器面板**：左边是本地电脑文件，右边是远端服务器文件，支持拖拽上传下载。 | “我想把双栏模式改成单栏模式”、“文件列表想要显示文件修改时间” |
| **`workspace/settings/`** | **设置中心主弹窗**：外观配置、快捷键设置、连接默认值、终端行为选项。 | “设置项太多了，想把分类重新排一下”、“增加一个界面开关” |
| **`workspace/overlay.rs`** | **弹窗遮罩层与模态框**：所有居中弹出确认框、对话框的统一承载机制。 | “弹窗背景透明度想要更深/更浅”、“点击遮罩外侧不要关闭弹窗” |
| **`workspace/notification_center.rs`** | **右下角/顶部通知气泡**：连接成功、断开连接、文件下载完成时的提示浮窗。 | “通知消失太快了”、“希望右上角有一个铃铛按钮查看历史通知” |
| **`workspace/ai_state.rs`** | **OxideSens AI 助手侧栏/浮层**：呼出 AI 对话助手，分析报错、生成命令。 | “想把 AI 对话窗口做成独立抽屉”、“对话框输入框样式调整” |

## 3. 核心功能与模块分类速查（所有 Crates 图谱）

OxideTerm 共有 70 多个 crate，按职责可以分为以下 6 大类：

### 类别 1：界面与用户交互类（前端层）
- **`oxideterm-gpui-app`**：整个应用的大脑与组装中心（见第 2 节）。
- **`oxideterm-gpui-ui`**：**通用 UI 积木库**。提供原生风格的按钮、输入框、复选框、下拉选择器、滑动条、图标容器。
- **`oxideterm-gpui-terminal`**：**终端画面渲染引擎**。把终端文字、颜色、光标通过 GPU 绘制到屏幕上。
- **`oxideterm-gpui-settings-view`**：**设置页面的视图组件**。设置界面里的各种开关、滑动条、输入框排版。
- **`oxideterm-theme`**：**主题配色中心**。暗黑模式（Dark）、明亮模式（Light）的主题色、背景色、文字颜色、边框颜色定义。
- **`oxideterm-i18n`**：**多语言国际化**。支持中、英、日、法、德等 11 国语言的翻译字典。

### 类别 2：终端功能与虚拟终端处理
- **`oxideterm-terminal`** / **`alacritty-terminal`** / **`vte`**：终端文字流解析引擎（负责解析命令行输出、换行、控制符）。
- **`oxideterm-terminal-model`**：终端数据状态模型（保存屏幕上每一行字、光标位置、回滚历史）。
- **`oxideterm-quick-commands`**：快捷命令库的数据存储与分类管理。
- **`oxideterm-terminal-triggers`**：终端触发器（比如当屏幕上出现“Password”字样时自动做某种反应）。
- **`oxideterm-terminal-recording`**：终端操作录像机（类似电影录制，可以回放敲命令过程）。
- **`oxideterm-trzsz`** / **`oxideterm-modem-transfer`**：终端内直接拖拽上传/下载文件的协议驱动。

### 类别 3：网络连接与服务器通信
- **`oxideterm-connections`**：**连接总调度器**。管理所有 SSH、本地 Shell、Telnet、串口连接的生命周期。
- **`oxideterm-ssh`**：**SSH 协议实现**。纯 Rust 编写的 SSH 客户端，负责与 Linux 服务器握手与认证。
- **`oxideterm-sftp`** / **`oxideterm-ftp`** / **`russh-sftp`**：SFTP 与 FTP 文件传输后台通道。
- **`oxideterm-forwarding`** / **`oxideterm-x11-forwarding`**：端口转发（内网穿透映射）与 X11 远程图形窗口转发。
- **`oxideterm-connection-monitor`**：网络健康检查与断线重连守护进程。

### 类别 4：数据存储、凭证与安全
- **`oxideterm-settings`** / **`oxideterm-settings-model`**：保存软件设置（如字体大小、默认启动行为）到本地配置文件。
- **`oxideterm-secret-store`**：**安全钥匙串**。使用 Windows DPAPI 系统底层加密保存服务器密码和私钥。
- **`oxideterm-cloud-sync`**：将配置或主机列表同步到自建 WebDAV / S3 云端。
- **`oxideterm-app-lock`**：主密码与应用锁（离开电脑时锁定软件窗口）。

### 类别 5：AI 与智能化运维
- **`oxideterm-ai`**：连接大模型（OpenAI、Claude、Gemini、本地 Ollama）的通信底层。
- **`oxideterm-ai-tasks`**：AI 后台任务执行与多轮对话状态机。
- **`oxideterm-public-mcp`**：支持 Model Context Protocol 协议，让 AI 能够调用外部系统工具。

### 类别 6：插件与扩展中心
- **`oxideterm-plugin-host-api`** / **`oxideterm-plugin-protocol`**：插件系统对外开放的接口定义。
- **`oxideterm-plugin-wasm-runtime`**：运行 Wasm 插件的安全沙箱引擎。
- **`oxideterm-remote-desktop`** / **`oxideterm-gpui-remote-desktop`**：RDP 远程桌面 / VNC 查看器模块。

## 4. 资源与静态文件速查（图标、字体、文案）

很多时候你“改界面”只是想换个图标、改个字、或者调个颜色，这些根本不需要动复杂代码：

| 想要调整的内容 | 对应存放位置 | 说明 |
| :--- | :--- | :--- |
| **界面展示文字 / 翻译** | `crates/oxideterm-i18n/locales/` | 里面有 `zh-CN.json`（简体中文）、`en-US.json`（英语）等。改动这里的文案立刻反映在界面上。 |
| **内置图标 (SVG/矢量)** | `assets/icons/` 或 `crates/oxideterm-gpui-app/src/assets.rs` | 各种操作按钮（新建、设置、关闭、复制、分屏）的矢量图标。 |
| **软件托盘与窗口主图标** | `crates/oxideterm-gpui-app/src/app_icon.rs` | 软件在任务栏、窗口左上角显示的 Logo。 |
| **配色方案 / 主题** | `crates/oxideterm-theme/` | 里面定义了各种配色方案的十六进制色值（Hex Color）。 |

## 5. “我想改……”小白提需求速查字典

当你想要调整功能或布局时，可以直接用下面的“自然语言公式”来提出要求，AI 就能秒懂：

| 你的想法场景 | 准确的业务模块描述 | 你可以对 AI 这样说： |
| :--- | :--- | :--- |
| **想调整命令输入栏** | `terminal_command_sender` (命令发送条) | *“我想调整底部快捷命令条，默认让它保持收起状态，只有按快捷键时才滑出来。”* |
| **想调整左侧服务器树** | `workspace/sidebar` (侧边栏) | *“我想给左侧主机列表的每个节点右侧增加一个‘快速打开 SFTP’的小按钮。”* |
| **想改变多标签页外观** | `workspace/tabs` (标签栏) | *“我想让标签页支持关闭按钮始终显示，并且把标签之间的左右内边距缩小一点。”* |
| **想调整分屏的展现** | `pane_tree` (分屏树) | *“我想在分屏右上角加一个微型操作工具栏，显示关闭、最大化当前窗格的图标。”* |
| **想修改某处的中文文案** | `oxideterm-i18n` (多语言) | *“‘快捷命令条’这个翻译我觉得太生硬，我想在界面上统一改叫‘指令广播栏’。”* |
| **想把某个按钮藏起来** | `workspace/root/render.rs` | *“顶栏右上角的 AI 助手小图标我暂时用不到，请帮我在顶栏把它隐藏。”* |
| **想调整弹窗/对话框** | `workspace/overlay.rs` (遮罩模态框) | *“确认弹窗的圆角太大、太突兀了，帮我把弹窗卡片的圆角改成 6px，显得硬朗一些。”* |

## 总结：你的极简上手路径

1. **不需要看一行 Rust 代码**。
2. 遇到不顺眼的界面，直接对照上表找到它的名字（例如“底部命令条”、“侧边栏”、“标签栏”）。
3. 用一两句简单的日常白话描述你的愿望。
4. 交给 AI 定位具体文件并执行最小安全修改。
5. 你在本地重新启动软件，亲眼验证视觉效果，如果不满意继续提“微调”要求即可！
